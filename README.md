# Personal Finance Advisor Bot

A responsive frontend replica inspired by the SkillWallet project dashboard shown in the reference.

## Features
- Personal Finance Advisor Bot overview
- Four project scenarios
- Skills and mentor section
- Project statistics
- Technical architecture
- System requirements
- Project progress panel
- Responsive mobile/desktop layout
- Interactive workflow accordion
- Demo/GitHub link buttons

## Run
No installation is required.

Open `index.html` in Google Chrome, Edge, or Firefox.

## GitHub
Upload all files in this folder to a GitHub repository. Enable GitHub Pages if you want a public demo link.
